# Loops — Explore

Explore caps exist so orientation finishes. Hitting a cap means **disclose and present**, not invent more detail.

**Markers:**

- `unknown` / open unknowns section — fact not confirmed this pass
- Never write `UNVERIFIED` into plan files (Explore does not own `assumptions.md`)

---

## Loop E1 — Scope clarification

| | |
|---|---|
| **Trigger** | Charter target cannot be inferred |
| **Runs** | Scope Setter |
| **Cap** | **1 question** |

**Exit:** charter exists, or a stated assumption substitutes for the answer.

**Cap behavior:** proceed with the best assumption and list it under unknowns.

---

## Loop E2 — Mapping breadth

| | |
|---|---|
| **Trigger** | Charter entities still unresolved |
| **Runs** | Cartographer |
| **Cap** | **3 map passes** |

**Body:** each pass opens files and cites them. After pass 3, stop even if gaps remain.

**Exit:** enough material for the chat map exit criteria (likely files + contracts + unknowns), or cap hit with gaps listed.

**Bounding:** cap caller-chasing at first ~50 matches per symbol; sample directories rather than reading every file; say so in the map.

---

## Loop E3 — Cite-check

| | |
|---|---|
| **Trigger** | Draft map exists |
| **Runs** | Citation Checker |
| **Cap** | **2 rounds** |

**Standard (one definition):** a claim about the repo is **kept** only if this role re-opened its `path:line` in this loop and the file still supports the claim. Otherwise **drop it** or move it to **Open unknowns** (worded as unknown, not as fact). There is no third grade such as “cite when possible.”

**Exit:** every bullet still in the presented map either (a) has a re-confirmed citation or (b) sits under Open unknowns. Zero uncited factual claims remain in Relevant areas / How it fits / Contracts.

**Cap behavior:** after 2 rounds, drop every still-contested claim; present the shortened map. Do not invent softer language to keep unconfirmed bullets.
